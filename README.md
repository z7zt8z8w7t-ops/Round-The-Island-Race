# Round the Island Regatta Companion

A sailing-themed PWA companion for the physical board game.

## Features
- 2–6 yachts
- Wind compass with 8 directions
- Board leg selection
- Automatic point-of-sail calculation
- Jib / Genoa / Spinnaker modifiers
- Capsize, Rocks, Calm Patch, Dirty Air, Lucky Gust, Favourable Tide
- Random Race Cards and Wind Cards
- Offline-capable PWA with local save state

## Run
Serve the folder from any static web server (GitHub Pages works well). Service workers do not run from file:// URLs.
